# 온브릿지 ONBRIDGE 홈페이지

네이비·샴페인 골드·아이보리 CI를 적용한 반응형 기업 소개 사이트입니다.

## 파일과 실행
- `dist/index.html`: 회사 소개·사업·상품·협업·문의 UI
- `dist/assets/style.css`: 반응형 스타일
- `dist/assets/app.js`: 상품 데이터·필터·상세 팝업·문의 초안 기능
- `dist/assets/hero.webp`: AI로 생성한 브랜드 연출 이미지
- `dist/assets/*.svg`: 확정 로고 시안을 참고해 구현한 웹용 심볼과 기획 예시 일러스트. 정밀 인쇄용 CI 원본이 아닙니다.
- `make-art.py`: 상품 예시 SVG 생성 스크립트

별도 패키지 설치 없이 정적 서버로 `dist` 폴더를 서비스합니다. 로컬에서는 `python -m http.server 8000 --directory dist`를 실행합니다.
일반 정적 호스팅의 공개 디렉토리는 `dist`로 지정합니다. `.openai/hosting.json`은 ChatGPT Sites 전용 배포 설정입니다.

## 구현 기능
- 화면 크기에 따른 레이아웃과 모바일 메뉴
- 상품 6종 기획 예시, 카테고리 필터, 상세 팝업
- 선택 상품을 문의 초안에 자동 반영
- 필수 입력 검증, 문의 초안 복사·TXT 다운로드
- 협업 FAQ와 개인정보 안내
- 외부 라이브러리·분석 추적 도구 없이 동작

## 운영 전 필요한 자료
실제 법인·사업자 정보, 연락처와 문의 수신처, 판매 가능한 상품·이미지·규격·가격·공급 조건, 정식 벡터 CI와 사용 권리 확인이 필요합니다. 다른 법인의 실적은 반영하지 않았습니다.

현재 문의는 **서버로 전송·접수되지 않습니다**. 방문자의 내용을 저장하는 백엔드, 결제, 회원·관리자 기능은 없습니다. 복사·파일 저장은 사용자가 명시적으로 선택할 때만 실행됩니다. 실제 접수 기능은 수신처·보관기간·개인정보 고지·스팸 방지 등을 확정한 후 구현합니다.

## 검증
JavaScript 구문, 로컬 정적 경로, PC 브라우저 렌더링, 상품 필터(6→3), 상품 상세, 문의 자동 입력과 이미지 로딩을 확인합니다. 모바일은 반응형 CSS를 포함하며 실제 휴대폰 시각 검수는 별도입니다.
