# 주식회사 온브릿지 홈페이지

굿즈·식음료 소개와 상품 등록을 위한 홈페이지입니다. 기존 기업 디자인을 보존하고 Vinext + Cloudflare D1/R2로 전환했습니다.

## 관리자 사용법
1. 홈페이지 하단 **상품 관리** 또는 `/admin`에 접속합니다.
2. 사이트 소유자 ChatGPT 계정으로 로그인합니다.
3. **관리 시작**을 누르면 기본 카테고리를 준비합니다(중복 생성하지 않습니다).
4. 카테고리 이름·순서를 수정하거나 새 카테고리를 추가합니다.
5. 상품명·카테고리·대표 사진·설명·규격·포장·가격 안내를 입력합니다.
6. 초안 / 홈페이지에 공개 / 보관을 선택하고 저장합니다. 공개 상품만 홈페이지에 표시됩니다.

사진은 JPG·PNG·WebP, 한 장당 5MB 이하입니다. 한 상품에 여러 사진을 첨부하고 대표 사진을 선택할 수 있습니다. 상품군·상품 개수에 프로그램상 고정 제한을 두지 않았으며, 실제 저장 가능량은 호스팅과 저장소 용량·사용 정책에 따릅니다.

사진으로 상품 빠르게 등록: 상품군과 공개 상태를 선택하고 여러 사진을 첨부하면, 사진 한 장당 상품 하나를 생성합니다. 파일명을 상품명으로 제안하고 등록 전 수정할 수 있습니다. 실제 등록은 등록 버튼을 누를 때만 실행합니다. 오류 시 이미 완료한 상품은 건너뛰고 미완료 항목부터 재시도합니다. 상품마다 발급한 ID로 중복 저장을 방지합니다.

상품 상세 화면에서 여러 사진을 썸네일로 전환할 수 있습니다. 상품과 카테고리는 D1에, 사진은 R2에 저장하여 브라우저나 기기를 바꿔도 유지합니다. 공개 상품이 아직 없으면 기존 기획 예시를 표시합니다. 첫 공개 상품 등록 후부터 실제 등록 상품만 표시합니다. 온라인 문의 접수·결제는 연결하지 않았습니다.

## 소스 구조
- app/content.ts: 기업 홈페이지 HTML
- app/catalog-server.ts: 권한 검사, 카테고리·상품·업로드 API
- app/admin/: 관리자 페이지
- public/assets/: 기존 디자인과 상품 관리 UI
- db/schema.ts, drizzle/: D1 스키마와 마이그레이션
- tests/catalog.test.cjs: 저장·공개·권한 검증

서버 런타임의 ADMIN_EMAIL은 현재 사이트 소유자 계정으로 제한합니다. 값은 Sites 환경변수에서만 관리하며 공개 소스에는 포함하지 않습니다. 상태 변경 API는 인증·소유자 이메일·요청 출처를 모두 확인합니다. SQL은 매개변수로 처리하고, 파일은 확장자 대신 실제 시그니처를 확인합니다.

## 개발
패키지는 pnpm-lock.yaml 기준입니다. 사이트 스킬의 설치·빌드·배포 절차를 따릅니다. `npm run db:generate`로 스키마 변경을 생성하고 로컬/운영 DB에 각자 적용합니다. 운영 도메인 인증값·비밀키·문의 내용은 저장소에 넣지 않습니다.

검증: 빌드, JS 구문, 로컬 SQLite 및 모의 R2로 관리자 인증·잘못된 출처·카테고리·사진 업로드·공개/초안/보관·카테고리 이름 변경·잘못된 카테고리 거부를 확인합니다. 실제 소유자 계정에서 사진을 등록하는 운영 브라우저 확인은 로그인 후 필요합니다.

## 간편 소개 등록 (최신)
이 사이트는 상품 소개 전용이며 결제·장바구니·주문 기능이 없습니다. /admin에 로그인하면 별도 관리 시작 없이 바로 입력할 수 있습니다. 대분류와 소분류를 선택하거나 선택칸 옆 +추가로 새 분류를 만듭니다. 여러 사진, 상품명, 상품 정보를 입력하고 선택적으로 가격 안내를 적은 뒤 소개 등록을 누릅니다. 가격 공란은 별도 문의로 표시됩니다. 첫 사진이 대표 사진이며 대표로 버튼으로 변경할 수 있습니다. 이전의 일괄 등록·별도 카테고리 관리 화면은 제거하고 한 장의 등록 폼으로 통합했습니다. 기존 상품과 사진, 규격·포장 데이터는 유지합니다. 기존 루트 분류 상품은 수정 시 기존 대분류 직접 등록 옵션으로 보존합니다.

### 수류기 소개 상품 8종
사용자가 제공한 `suryugi_photoreal_8products.zip`에서 피규어·자석·볼펜·연필 2종·물병 3종을 등록했습니다. 원본 대표/상세 이미지를 WebP로 최적화하고, 제품 설명에 AI 예상 이미지 및 제작 전 기획 사양임을 표시합니다. 가격은 별도 문의입니다.
`app/suryugi-data.json`은 등록 자료이며 `app/suryugi-seed.ts`가 첫 카탈로그 또는 관리자 조회 때 D1/R2에 누락된 상품만 가져옵니다. 기존 상품의 수정·사진·공개 상태는 덮어쓰지 않습니다. 판매·결제 기능은 없습니다.

### 소개용 상품군 추가
만상사 공개 상품군 안내를 참고한 자체 일러스트 20종과 식음료 구성 예시 4종을 `app/catalog-examples.json`으로 추가했습니다. 참고 상품에는 원문 링크와 참고 표시를 노출하며 실제 공급 계약·타사 캐릭터 사용권·자사 제작 실적을 주장하지 않습니다. 외부 사진은 복제하지 않습니다. 편집 가능한 원본 SVG와 등록 정보는 `catalog-import/`에 있습니다.
첫 조회 때 누락된 예시만 기존 D1/R2 카탈로그에 추가됩니다. 기존 수류기 제품과 관리자 수정·숨김은 보존됩니다.

### 제공 상품 사진과 실제 식음료 사진
첨부한 11개 화면의 사진 44장을 상품 36개로 묶어 기존 수류기 8종과 함께 표시합니다. 임시 참고 일러스트 20개는 보관 상태로 전환하고 식음료 4종은 실제 촬영 참고 사진으로 교체했습니다. 현재 공개 카탈로그는 48개입니다.
상품별 분류와 사진 묶음은 `catalog-photos/goods-manifest.json`, 식음료 출처·이용허락은 `catalog-photos/photo-credits.json`에 기록합니다. 압축한 사진은 `app/uploaded-products.json`과 `app/food-photos.json`에 포함되어 D1/R2로 등록됩니다. 기존 관리자 수정·공개 상태는 유지하고, 식음료 원본 일러스트 키에 대해서만 사진 교체를 수행합니다.

### 공개 상품 사진 교체
대표님이 추가 제공한 실제 상품 사진을 반영해 공개 항목을 48개로 정리했습니다(수류기 8개 + 첨부 굿즈 36개 + 식음료 4개). 상품군 임시 일러스트 20개는 보관 처리됩니다. 식음료 사진은 실제 취급 제품을 단정하는 사진이 아닌 실제 촬영 참고 사진이며, 촬영자·원문·이용허락은 상품 설명과 사진 출처 파일에 표시합니다.
